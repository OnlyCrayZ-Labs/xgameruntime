# xgameruntime — MSFS 2024 Linux

Part of **MSFS 2024 Linux – Experimental First Playable Source Preview** by
[OnlyCrayZ-Labs](https://github.com/OnlyCrayZ-Labs/MSFS2024-Linux).
This experimental open-source runtime component builds on
[xodus-gaming/xgameruntime](https://github.com/xodus-gaming/xgameruntime).

The recorded private milestone used the Microsoft Store / Xbox PC edition of
MSFS 2024, with a standard aircraft included with the game, on CachyOS Linux
and an NVIDIA RTX 5090. Cockpit, landscape, instruments and user input worked
in the user-reported test. The public source revisions have not been validated
as a reproducible clean installation or verified binary runtime release.

Fenix A320, Navigraph, BeyondATC and other third-party add-ons are not validated.
Xbox cloud-save synchronization is not implemented. A legitimate game license
is required. This community project is not officially affiliated with Microsoft
or Asobo. No game files, account data, prefixes or binary packages are provided.

scope, and [tests/README.md](tests/README.md) for synthetic test guidance.
